## 正本の入れ替えで下流に起きる変化（要対応）

- 艦級名から年の混入が消える。艦級名の年を使っていたもの（`navspec_common.parse_year`、`shipknow_extract` など）は、新設の `CLASS.WHEN_DATE` を優先するよう直す必要がある。直さないと、例えば大和は 1942 → 1934 になる。
- 群れ要約表の艦級（2,758）は、SHIPS に行が無くなる（旧 DB では空行 1 行だった）。`SELECT WHEN_DATE FROM SHIPS ...` の副問い合わせは NULL になる。
- `Fate_WHY` の空白保持や、テキスト節の改行区切りで、文字列の形が変わる。
- 既存の生成データ（navspec v0.2、shipknow v0/v0_1/v1/v1_1）は旧 DB から作ったもの。入れ替えても、作り直すまでは変わらない。
